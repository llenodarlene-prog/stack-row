# Privacy Policy

Effective October 3, 2026

Stack Row is a static publication. The current site does not provide user accounts, comments, payment processing, or contact forms.

## Server logs

The hosting provider may process standard server logs needed to deliver and protect the website. These logs can include an IP address, request time, requested URL, browser information, and response status.

## Fonts

The site requests fonts from Google Fonts. Google may receive technical request information when those font files load.

## Cookies and analytics

The repository does not currently add analytics scripts or advertising cookies. This policy must be reviewed before any analytics, advertising, embedded media, newsletter, or form service is introduced.

## Policy changes

This page will be updated when the site's data practices change.
