Works like JavaScript encodeURIComponent. Up to 100 KB.

A plus sign stays a plus sign here. Use Form encoding if + means a space.

Include the scheme, such as https://. The URL is only read as text. Nothing is fetched.

Paste a URL or text such as a=1&b=2, then edit the parameters below. Order and repeated keys are kept.

Parameters

application/x-www-form-urlencoded, the format HTML forms send. A space is written as +.
