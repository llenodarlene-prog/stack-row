# Stack Row Brand System

## Positioning

Stack Row is a technically fluent publication for people who operate, buy, secure, and scale business technology. It is not a consumer technology news site.

Tagline: **Tech That Moves Businesses Forward.**

## Colors

| Token | Hex | Use |
|---|---|---|
| Deep Navy | `#0B2A56` | Navigation, footer, headings, trust-oriented UI |
| Electric Blue | `#2563EB` | Primary actions, links, charts, active states |
| Cyan | `#22D3EE` | Sparse technical highlights and data accents |
| Soft White | `#F8FAFC` | Main background and light cards |
| Slate | `#374151` | Body copy, metadata, tables, neutral UI |
| White | `#FFFFFF` | Cards and contrast text |

Recommended balance: 55 to 65 percent white or soft white, 20 to 25 percent navy, 5 to 8 percent slate, 4 to 6 percent electric blue, and 2 to 3 percent cyan.

## Typography

- H1 and H2: Sora, 500 to 600
- H3: Sora, 500
- Body: Inter, 400
- Navigation and buttons: Inter, 500
- Technical accents: IBM Plex Mono, used sparingly

## Visual direction

Use clean, modular, systems-oriented layouts. Suitable imagery includes modern infrastructure, glass architecture, server and data environments, developer tooling, dashboards, security operations, and restrained system diagrams.

Avoid robot heads, glowing brains, random node webs, code rain, gaming neon, and glossy generic SaaS illustration.

## UI rules

- Keep card corners between 6 and 10 pixels.
- Use clean borders and little or no shadow.
- Do not turn every section into a blue gradient.
- Use cyan as a signal, not a background default.
